# HUNT — source handover

This is the current application source, copied from the local HUNT workspace. It is an incomplete product; the repository is not proof of autonomous job applications.

The hunt folder includes the Python application, cloud Worker, browser code, dashboard, writing rules and tests. SOURCE-MANIFEST.json records hashes of the copied source files. Runtime databases, CV files, emails, environment secrets, OAuth credentials, build outputs and Git history are excluded.

Some execution code is unfinished. Consult the current release evidence before claiming a feature works. The hosted platform configuration is intentionally excluded; deployments need an owner-selected hosting configuration and private service credentials.
